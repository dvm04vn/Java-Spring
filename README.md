# Java Spring Backend

Đây là dự án backend cá nhân được xây dựng bằng **Spring Boot**.

Dự án này được tạo ra nhằm mục đích học tập, thực hành và xây dựng nền tảng backend với Java. Thông qua dự án, tác giả làm quen với cách xây dựng RESTful API, tổ chức cấu trúc thư mục, xử lý dữ liệu đầu vào và phát triển ứng dụng backend theo hướng thực tế.

## Giới thiệu về Spring Boot

**Spring Boot** là một framework mã nguồn mở dựa trên **Spring Framework** của ngôn ngữ Java.

Spring Boot giúp lập trình viên xây dựng các ứng dụng web, dịch vụ backend, RESTful API và hệ thống Microservices một cách nhanh chóng, dễ dàng nhờ việc tự động hóa các cấu hình phức tạp.
